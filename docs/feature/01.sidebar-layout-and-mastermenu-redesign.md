# 01. Sidebar Layout And Master Menu Redesign

## Goal
- Improve UI quality from plain screens to a more intentional visual style.
- Reorganize navigation so Master Menu is one item inside a left sidebar, enabling future expansion.

## Scope
- Frontend only (`src/Takazono.Ojt.Web`).
- Add sidebar structure in shared layout template.
- Add dashboard route/page as landing entry.
- Redesign master menu cards and header style.

## Non-Scope
- Backend/API changes.
- Master CRUD behavior changes.
- Permission-based menu visibility.

## Implemented
- Added dashboard route and page.
- Switched post-login landing to dashboard.
- Added responsive sidebar navigation in Base template.
- Updated Header visual style.
- Redesigned Master Menu with hero section and richer cards.
- Extended i18n labels for new menu/dashboard terms.
- Updated theme typography and palette settings.
