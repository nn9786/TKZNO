# 02. Coding Guideline Markdown And CSS Alignment

## Goal
- Reformat the coding guideline document into valid, readable Markdown while preserving its rule content.
- Align existing frontend implementation with the CSS rules, especially reducing direct inline `sx` object usage.

## Scope
- `docs/code` markdown reorganization.
- Frontend style refactor in `src/Takazono.Ojt.Web` components/pages.

## Implemented
- Rewrote `docs/code` into structured Markdown (headings/lists/table/code blocks).
- Replaced direct inline `sx={{ ... }}` blocks with `styles` constants in major pages/components.
- Standardized several hardcoded color values to uppercase hex style where touched.
- Kept behavior and UI structure unchanged.
